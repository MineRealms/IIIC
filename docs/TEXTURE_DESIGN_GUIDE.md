## 颜色代码

### 基础金属层
- `■` 深色边框: `#2A2A2A` (RGB: 42, 42, 42)
- `□` 浅灰高光: `#5A5A5A` (RGB: 90, 90, 90)
- `▓` 中灰金属: `#4A4A4A` (RGB: 74, 74, 74)
- `░` 深灰金属: `#3C3C3C` (RGB: 60, 60, 60)

### 能量发光层
- `●` 最亮青色: `#00FFFF` (RGB: 0, 255, 255) - 核心
- `◆` 中等青色: `#00CCCC` (RGB: 0, 204, 204) - 外围

### 可选装饰
- 四角螺栓位置: (1,1), (14,1), (1,14), (14,14)
- 螺栓颜色: `#1A1A1A` (RGB: 26, 26, 26)

## Photoshop/GIMP 制作步骤

1. **创建画布**: 16x16 像素，RGB 模式
2. **绘制边框**: 1px 深色边框 `#2A2A2A`
3. **填充金属层**: 
   - 内部填充深灰 `#3C3C3C`
   - 添加 2px 中灰边缘 `#4A4A4A`
   - 添加 1px 浅灰高光 `#5A5A5A`
4. **绘制能量核心**:
   - 中心 2x2 像素最亮青色 `#00FFFF`
   - 外围 6x6 像素中等青色 `#00CCCC`
   - 使用高斯模糊 0.5px 制造发光效果
5. **添加细节**:
   - 四角螺栓（1x1 深色点）
   - 金属噪点（添加 1-2% 噪点）
6. **保存**: PNG 格式，无压缩
