# 工业集成系统完整报告

## 系统概述

本系统为 ImprovedMobs 模组提供了基于 GregTech CEu 的工业集成，通过污染和电压等级动态调整游戏难度。

---

## 一、污染系统（双层设计）

### 1.1 临时污染（Temporary Pollution）
- **性质**：基于区块的扩散污染
- **来源**：机器运行产生
- **特点**：
  - 可被环境（树叶、草、花、水）吸收
  - 触发怪物攻击机器的条件
  - 不直接影响 difficulty

#### 产生速率
```
单方块机器：0.01 * (1 + tier * 0.5) 污染/秒
多方块机器：单方块 * 3

示例：
- ULV (T0): 0.01/s
- LV  (T1): 0.015/s
- MV  (T2): 0.02/s (多方块 0.06/s)
- HV  (T3): 0.025/s (多方块 0.075/s)
- EV  (T4): 0.03/s (多方块 0.09/s)
```

#### 衰减机制
```
基础衰减：0.05/秒
环境净化：
- 树叶：0.0001/方块
- 水：0.00005/方块
- 草/花：0.0001/方块

净衰减 = 0.05 + 环境净化 - 机器产生
```

### 1.2 永久污染（Permanent Pollution）
- **性质**：全局累积的污染值
- **来源**：临时污染转化
- **特点**：
  - 直接增加 ImprovedMobs 的 difficulty
  - 代表长期工业发展的环境影响
  - 不可逆转

#### 转化机制
```
转化条件：临时污染 > 200
转化速率：0.001 * 临时污染 每秒
转化为 difficulty：每累积 0.1 永久污染 = +0.1 difficulty
```

## 二、威胁系统（基于电压等级）

### 2.1 MV 阶段（Tier 2）
**特征**：被动威胁

- **触发条件**：局部污染 >= 50
- **威胁类型**：附近僵尸会攻击机器
- **机制**：通过 AI 实现，不主动生成

### 2.2 HV 阶段（Tier 3+）
**特征**：主动威胁

#### 僵尸生成
- **触发条件**：
  - 平均电压 >= HV (Tier 3)
  - 局部污染 >= 80
- **生成概率**：1% 每秒
- **行为**：主动攻击机器

#### Creeper 生成
- **触发条件**：
  - 平均电压 >= HV (Tier 3)
  - 局部污染 >= 120
- **生成概率**：0.5% 每秒
- **行为**：主动攻击机器并自爆

#### 闪电苦力怕
- **触发条件**：
  - 平均电压 >= HV (Tier 3)
  - 局部污染 >= 200
- **生成概率**：0.1% 每秒（在 Creeper 生成时额外判定）
- **特殊效果**：生成时召唤闪电

## 三、Difficulty 多元化系统

### 3.1 贡献因素

ImprovedMobs 的 difficulty 由以下因素累加：

```
总 Difficulty = 基础难度 + 工业加成

工业加成 = 玩家工业加成 * 1.0
          + 局部临时污染 * 0.5
          + 全局永久污染 * 0.3
          + 时间因子 * 0.2
```

#### 玩家工业加成
- 基于玩家附近64格内的机器电压和污染
- 实时计算，动态变化
- 公式：`techWeight * 电压因子 + pollutionWeight * 污染因子`

#### 局部临时污染
- 归一化：100 污染 = 1.0 difficulty
- 权重：0.5

#### 全局永久污染
- 归一化：50 永久污染 = 1.0 difficulty
- 权重：0.3

#### 时间因子
- 归一化：100 天 = 1.0 difficulty
- 最大值：2.0
- 权重：0.2

### 3.2 数值示例

#### 场景 1：早期 MV 阶段
```
游戏天数：30天
机器：10台 MV 单方块 + 2台 MV 多方块
临时污染：50（刚达到僵尸攻击阈值）
永久污染：0

计算：
- 玩家工业加成：~0.5
- 局部污染：50/100 * 0.5 = 0.25
- 全局污染：0
- 时间因子：30/100 * 0.2 = 0.06

工业加成 = 0.5 + 0.25 + 0 + 0.06 = 0.81
```

#### 场景 2：中期 HV 阶段
```
游戏天数：100天
机器：40台 HV 单方块 + 5台 HV 多方块
临时污染：150（Creeper 开始生成）
永久污染：10

计算：
- 玩家工业加成：~1.5
- 局部污染：150/100 * 0.5 = 0.75
- 全局污染：10/50 * 0.3 = 0.06
- 时间因子：100/100 * 0.2 = 0.2

工业加成 = 1.5 + 0.75 + 0.06 + 0.2 = 2.51
```

#### 场景 3：后期 IV-LuV 阶段
```
游戏天数：300天
机器：100+台 IV-LuV 机器
临时污染：250（闪电苦力怕频繁生成）
永久污染：50

计算：
- 玩家工业加成：~3.0
- 局部污染：250/100 * 0.5 = 1.25
- 全局污染：50/50 * 0.3 = 0.3
- 时间因子：2.0（上限）* 0.2 = 0.4

工业加成 = 3.0 + 1.25 + 0.3 + 0.4 = 4.95
```

## 四、配置参数

### 4.1 污染系统
```properties
# 临时污染转化为永久污染的阈值
tempToPermanentThreshold = 200.0

# 临时污染转化率（每秒转化的比例）
tempToPermanentRate = 0.001

# 永久污染对 difficulty 的转化率
permanentToDifficultyRate = 0.1
```

### 4.2 威胁系统
```properties
# MV 阶段：僵尸攻击机器的污染阈值
mvZombieAttackThreshold = 50.0

# HV 阶段：主动生成僵尸的污染阈值
hvZombieSpawnThreshold = 80.0

# HV 阶段：主动生成 Creeper 的污染阈值
hvCreeperSpawnThreshold = 120.0

# 闪电苦力怕生成的污染阈值
chargedCreeperThreshold = 200.0

# 生成概率（每秒）
zombieSpawnChance = 0.01      # 1%
creeperSpawnChance = 0.005    # 0.5%
chargedCreeperChance = 0.001  # 0.1%
```

### 4.3 Difficulty 权重
```properties
# 玩家工业加成权重
playerBonusWeight = 1.0

# 局部临时污染权重
localPollutionWeight = 0.5

# 全局永久污染权重
globalPollutionWeight = 0.3

# 时间因子权重
timeFactorWeight = 0.2
```

## 五、性能优化

### 5.1 异步处理
- 污染扫描：异步线程池处理
- 机器检测：CompletableFuture 异步
- 环境净化计算：后台线程

### 5.2 更新频率
- 污染计算：每秒（20 ticks）
- 环境净化缓存：每5分钟（6000 ticks）
- HUD 更新：每秒
- 威胁检测：每秒

### 5.3 缓存机制
- 电压等级缓存
- 环境净化缓存
- 污染 EMA 平滑

## 六、游戏阶段平衡

### 6.1 MV 阶段（20-30台机器）
```
预期污染：30-60/区块
威胁等级：低（僵尸偶尔攻击）
difficulty 增加：+0.5 - +1.0
游戏体验：轻微压力，提醒玩家注意环境
```

### 6.2 HV 阶段（40-60台机器）
```
预期污染：80-150/区块
威胁等级：中（僵尸和 Creeper 主动生成）
difficulty 增加：+1.5 - +2.5
游戏体验：明显压力，需要防御措施
```

### 6.3 IV-LuV 阶段（100+台机器）
```
预期污染：150-300/区块
威胁等级：高（频繁生成，包括闪电苦力怕）
difficulty 增加：+3.0 - +5.0
游戏体验：高压力，需要完善的防御系统
```

### 6.4 ZPM-UHV 阶段（200+台机器）
```
预期污染：300+/区块
威胁等级：极高（持续威胁）
difficulty 增加：+5.0+
游戏体验：极限挑战，需要自动化防御
```

## 十、技术细节

### 10.1 架构
```
PollutionManager (污染管理)
    ├── 临时污染计算
    ├── 永久污染转化
    └── 环境净化

ThreatManager (威胁管理)
    ├── 电压等级检测
    ├── 威胁触发判定
    └── 怪物生成

IndustrialDifficultyGetter (难度提供)
    ├── 玩家工业加成
    ├── 污染因子
    └── 时间因子

TriAxisDifficultyManager (三轴难度)
    ├── 时间轴
    ├── 电压轴
    └── 污染轴
```

### 10.2 数据流
```
机器运行 → 临时污染产生 → 区块扩散
    ↓
临时污染 > 阈值 → 永久污染转化
    ↓
永久污染累积 → difficulty 增加
    ↓
difficulty 增加 → 怪物属性增强
```
